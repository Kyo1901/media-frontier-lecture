# 내 연습장 — ★ 4단계 (6일차 · 실습 ⑥ 을 «다 끝낸» 사람만)

> 🔴 **오늘은 실습 ⑥ 제출이 먼저입니다.** 다 끝냈고 시간이 남을 때만 하십시오. 과제가 아닙니다.

## ① 색을 변수로 — 오늘 배운 것

연습장 `style.css` 에 흩어진 색(`#1f5065` · `#d5dee5` …)을 맨 위 `:root` 로 모읍니다.

```css
:root {
  --brand: #1f5065;
  --line: #d5dee5;
}
header { background: var(--brand); }
.box, .chart { border: 1px solid var(--line); }
```

`--brand` 한 줄을 바꿔 보십시오 — 머리 색이 **한 번에** 바뀌면 다 묶은 것입니다.

## ② 표 하나 — 미니프로젝트의 「주요 수치」

분석 결과 절 아래에 표를 하나 둡니다 (2일차 「표의 뼈대」).

```html
<table>
  <thead><tr><th>무리</th><th class="num">건수</th></tr></thead>
  <tbody><tr><td>예) 로맨스</td><td class="num">392</td></tr></tbody>
</table>
```

```css
table { width: 100%; border-collapse: collapse; }   /* 🔴 없으면 테두리가 두 줄로 벌어진다 */
th, td { padding: 8px 12px; border-bottom: 1px solid var(--line); text-align: left; }
.num { text-align: right; }                          /* 숫자는 오른쪽 — 자릿수가 맞는다 */
```
