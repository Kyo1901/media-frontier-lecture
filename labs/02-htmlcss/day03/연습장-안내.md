## 오늘 할 것

**`index.html` 을 빈 파일부터** 씁니다. 1~2일차에 배운 태그만 씁니다.

| ☐ | 무엇 | 배운 곳 |
| --- | --- | --- |
| ☐ | 문서 뼈대 — `<!DOCTYPE html>` · `<html lang="ko">` · `<head>` · `<meta charset>` · `<title>` | 1일차 |
| ☐ | `<link rel="stylesheet" href="style.css">` | 오늘 |
| ☐ | `header` — 제목(`h1`) 한 줄 · 소개 문장(`p`) 한 줄 | 1일차 |
| ☐ | `nav` — 링크 둘: **소개** · **분석 결과** | 2일차 |
| ☐ | `main` 안에 `section` 둘 — 「01. 소개」 · 「02. 분석 결과」 (`h2`) | 1일차 |
| ☐ | 소개 절 — 주제 한 줄 · 궁금한 것 셋(`ol`) | 2일차 |
| ☐ | 분석 결과 절 — `img`(`images/chart-here.png`, `alt` 까지) · 해석 자리 `p` | 2일차 |
| ☐ | `footer` — 한 줄 | 1일차 |

### 🟢 메뉴를 누르면 그 절로 — 오늘 배운 `id`

```html
<nav>
  <a href="#intro">소개</a>
  <a href="#results">분석 결과</a>
</nav>
...
<section id="intro">…</section>
<section id="results">…</section>
```

`href="#이름"` 은 **같은 페이지의 `id="이름"`** 으로 갑니다. 🔴 `#` 은 링크 쪽에만, `id` 에는 안 붙입니다.

### `style.css` — 세 가지만

1. 오늘 배운 **「맨 위에 이 세 줄」**(`box-sizing`)
2. `header` 에 배경색 · 글자색
3. `section` 에 위아래 여백 (`margin`)
