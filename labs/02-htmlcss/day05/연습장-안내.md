## 오늘 할 것

### ① 🆕 차트 한 장 = `figure` 하나

분석 결과 절의 `img` 를 이렇게 감쌉니다. `figure` · `figcaption` 은 **처음 보는 태그**입니다 —
하는 일은 `div` 와 같고, **「그림과 그 설명」이라는 이름**이 붙었을 뿐입니다 (1일차 「이름이 있는 상자들」).

```html
<div class="chart-grid">
  <figure class="chart">
    <img src="images/chart-here.png" alt="여기에 들어갈 차트 1 자리">
    <figcaption>
      <h3>차트 1 · 제목</h3>
      <p>숫자 하나 + 뜻 하나</p>
    </figcaption>
  </figure>
  <!-- figure 를 하나 더 복사해 두 장으로 -->
</div>
```

### ② 차트 카드 판 — 오늘 배운 Grid

```css
img { max-width: 100%; height: auto; display: block; }   /* 🔴 이 줄부터 */

.chart-grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(460px, 1fr)); gap: 16px; }
.chart      { border: 1px solid #d5dee5; border-radius: 10px; overflow: hidden; }

@media (max-width: 700px) {
  .intro      { flex-direction: column; }
  .chart-grid { grid-template-columns: 1fr; }
}
```

- 차트는 넓어야 읽히므로 최소 폭을 **460px** 로 잡았습니다 (수업의 카드는 280px)
- 그래서 휴대폰 폭에서는 미디어 쿼리로 **한 줄**로 바꿉니다

## 확인 — 🔴 기기 모드로

`F12` → `Ctrl+Shift+M` → 폭을 **375** 로.

- **가로 스크롤**이 안 생기는가 — 생기면 `img { max-width: 100% }` 를 확인
- 차트가 **한 줄**로, 소개 칸이 **세로로** 쌓이는가
- 다시 넓히면 차트가 **두 줄**이 되는가
