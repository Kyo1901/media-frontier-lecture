```html
<section id="intro">
  <h2>01. 소개</h2>
  <div class="intro">
    <article class="box"> <h3>주제</h3> … </article>
    <article class="box"> <h3>궁금한 것</h3> <ol>…</ol> </article>
    <article class="box"> <h3>만든 사람</h3> … </article>
  </div>

```

```css
.intro { display: flex; gap: 16px; }
.box   { flex: 1; border: 1px solid #d5dee5; border-radius: 10px; padding: 16px; }
```
