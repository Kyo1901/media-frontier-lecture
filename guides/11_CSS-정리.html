CSS 기본

CSS란? ★ 3일차

CSS (Cascading Style Sheets): HTML 요소의 스타일을 정의하는 언어

CSS 적용 방법 ★ 3일차

1. 인라인 스타일

<p style="color: red; font-size: 16px;">텍스트</p>

2. 내부 스타일시트

<head>
  <style>
    p {
      color: blue;
      font-size: 16px;
    }
  </style>
</head>

3. 외부 스타일시트 (권장)

<head>
  <link rel="stylesheet" href="style.css">
</head>

/* style.css */
p {
  color: green;
  font-size: 16px;
}

선택자 종합 표

구분 이름 의미 형태 예시
기본 선택자 전체 선택자 ★ 모든 요소 선택 * * { margin: 0; }
요소(태그) 선택자 ★ 특정 태그 요소 선택 태그명 p { color: black; }
클래스 선택자 ★ 특정 클래스를 가진 요소 선택 .클래스명 .btn { padding: 10px; }
ID 선택자 ★ 특정 ID를 가진 요소 선택 #아이디명 #header { background: #333; }
복합 선택자 그룹 선택자 ★ 여러 요소를 한 번에 선택 선택자, 선택자 h1, h2, h3 { font-family: Arial; }
자손 선택자 ★ 특정 요소의 모든 하위 요소 선택 선택자 선택자 (공백) div p { color: blue; }
자식 선택자 ★ 특정 요소의 직계 자식 요소만 선택 선택자 > 선택자 div > p { color: red; }
인접 형제 선택자 바로 다음에 오는 형제 요소 선택 선택자 + 선택자 h1 + p { font-weight: bold; }
일반 형제 선택자 이후의 모든 형제 요소 선택 선택자 ~ 선택자 h1 ~ p { margin-top: 10px; }
속성 선택자 속성 존재 선택자 특정 속성을 가진 요소 선택 [속성] a[href] { color: blue; }
속성 값 일치 선택자 속성 값이 정확히 일치하는 요소 선택 [속성="값"] a[href="https://example.com"] { color: green; }
속성 값 포함 선택자 속성 값에 특정 문자열이 포함된 요소 선택 [속성*="값"] a[href*="google"] { color: red; }
속성 값 시작 선택자 속성 값이 특정 문자열로 시작하는 요소 선택 [속성^="값"] a[href^="https"] { font-weight: bold; }
속성 값 끝 선택자 속성 값이 특정 문자열로 끝나는 요소 선택 [속성$="값"] a[href$=".pdf"] { background: url(pdf-icon.png); }
가상 클래스 선택자 :hover ★ 마우스를 올렸을 때 선택자:hover a:hover { color: red; }
:active 클릭하고 있을 때 선택자:active a:active { color: blue; }
:visited 방문한 링크 선택자:visited a:visited { color: purple; }
:focus 포커스를 받았을 때 선택자:focus input:focus { border: 2px solid blue; }
:focus-visible ★ 키보드로 포커스를 받았을 때만 선택자:focus-visible a:focus-visible { outline: 2px solid; }
:first-child 첫 번째 자식 요소 선택자:first-child li:first-child { font-weight: bold; }
:last-child ★ 마지막 자식 요소 선택자:last-child li:last-child { border-bottom: none; }
:nth-child(n) n번째 자식 요소 선택자:nth-child(n) li:nth-child(2) { color: red; }
:nth-child(odd) 홀수 번째 자식 요소 선택자:nth-child(odd) li:nth-child(odd) { background: #f0f0f0; }
:nth-child(even) 짝수 번째 자식 요소 선택자:nth-child(even) li:nth-child(even) { background: #fff; }
:not(선택자) 특정 선택자를 제외한 요소 선택자:not(제외할선택자) p:not(.intro) { font-size: 14px; }
가상 요소 선택자 ::first-letter 첫 글자 선택 선택자::first-letter p::first-letter { font-size: 2em; }
::first-line 첫 줄 선택 선택자::first-line p::first-line { color: blue; }
::before 요소 앞에 내용 추가 선택자::before h1::before { content: "📌 "; }
::after 요소 뒤에 내용 추가 선택자::after h1::after { content: " ✓"; }
::selection 사용자가 선택한 텍스트 ::selection ::selection { background: yellow; }

복합 선택자

그룹 선택자 ★ 6일차

h1, h2, h3 {
  font-family: Arial, sans-serif;
}

자손 선택자 (공백) ★ 3일차

/* div 안의 모든 p 요소 */
div p {
  color: blue;
}

자식 선택자 (>) ★ 3일차

/* div의 직계 자식 p 요소만 */
div > p {
  color: red;
}

인접 형제 선택자 (+)

/* h1 바로 다음에 오는 p 요소 */
h1 + p {
  font-weight: bold;
}

일반 형제 선택자 (~)

/* h1 이후의 모든 p 형제 요소 */
h1 ~ p {
  margin-top: 10px;
}

속성 선택자

/* href 속성을 가진 a 요소 */
a[href] {
  color: blue;
}

/* href가 정확히 일치 */
a[href="https://example.com"] {
  color: green;
}

/* href에 "google"이 포함 */
a[href*="google"] {
  color: red;
}

/* href가 "https"로 시작 */
a[href^="https"] {
  font-weight: bold;
}

/* href가 ".pdf"로 끝남 */
a[href$=".pdf"] {
  background: url(pdf-icon.png);
}

가상 클래스 선택자 ★ 3·4·6일차 — :hover · :last-child · :focus-visible

/* 마우스 오버 */
a:hover {
  color: red;
}

/* 활성화 (클릭) */
a:active {
  color: blue;
}

/* 방문한 링크 */
a:visited {
  color: purple;
}

/* 포커스 */
input:focus {
  border: 2px solid blue;
}

/* 키보드로 다닐 때만 포커스 표시 (마우스 클릭엔 안 뜬다) — 6일차 */
a:focus-visible {
  outline: 2px solid blue;
  outline-offset: 2px;
}

/* 첫 번째 자식 */
li:first-child {
  font-weight: bold;
}

/* 마지막 자식 */
li:last-child {
  border-bottom: none;
}

/* n번째 자식 */
li:nth-child(2) {
  color: red;
}

/* 홀수 번째 */
li:nth-child(odd) {
  background: #f0f0f0;
}

/* 짝수 번째 */
li:nth-child(even) {
  background: #ffffff;
}

/* 첫 글자 */

가시성

display ★ 4일차

요소의 표시 방식

div {
  display: block;        /* 블록 요소 */
  display: inline;       /* 인라인 요소 */
  display: inline-block; /* 인라인 + 블록 특성 */
  display: none;         /* 숨김 (공간도 차지 안함) */
  display: flex;         /* Flexbox */
  display: grid;         /* Grid */
}

블록 레벨 요소 vs 인라인 요소

블록 레벨 요소

  • 새로운 줄에서 시작하고 전체 너비를 차지
  • 예: <div>, <p>, <h1>, <ul>, <section>, <header> 등

인라인 요소

  • 줄 바꿈 없이 내용만큼의 공간만 차지
  • 예: <span>, <a>, <strong>, <img>, <input> 등

visibility

요소 표시/숨김

div {
  visibility: visible; /* 보임 */
  visibility: hidden;  /* 숨김 (공간은 차지함) */
}

opacity

투명도

div {
  opacity: 1;   /* 불투명 */
  opacity: 0.5; /* 반투명 */
  opacity: 0;   /* 완전 투명 */
}

크기와 단위

절대 단위 ★ 3일차 — px

div {
  width: 100px;  /* 픽셀 */
  width: 1cm;    /* 센티미터 */
  width: 1in;    /* 인치 */
  width: 1pt;    /* 포인트 */
}

상대 단위

%

부모 요소 기준

.child {
  width: 50%; /* 부모의 50% */
}

em

font-size 에 쓰면 부모의 글자 크기 기준, 그 밖의 속성(padding 등)에 쓰면 자기 글자 크기 기준

.parent {
  font-size: 16px;
}

.child {
  font-size: 2em;   /* 32px */
  padding: 1em;     /* 32px — 자기 font-size(32px) 기준 */
}

rem

루트(html) 요소의 font-size 기준

html {
  font-size: 16px;
}

div {
  font-size: 2rem;  /* 32px */
  padding: 1rem;    /* 16px */
}

vw / vh

뷰포트(브라우저 창) 크기 기준

div {
  width: 50vw;   /* 뷰포트 너비의 50% */
  height: 100vh; /* 뷰포트 높이의 100% */
}

ch ★ 6일차

0 한 글자의 폭 — 글줄 길이를 정할 때 (한글은 1ch 에 약 0.65자)

.article p {
  max-width: 62ch; /* 한글로 40자쯤 — 6일차에 재 본 값 */
}

vmin / vmax

뷰포트의 작은/큰 쪽 기준

div {
  width: 50vmin;  /* vw와 vh 중 작은 값의 50% */
  height: 50vmax; /* vw와 vh 중 큰 값의 50% */
}

박스 모델

모든 HTML 요소는 박스로 구성됨: Content → Padding → Border → Margin

+------------------ margin ------------------+
|  +--------------- border ---------------+  |
|  |  +------------ padding ------------+ |  |
|  |  |                                 | |  |
|  |  |            content              | |  |
|  |  |                                 | |  |
|  |  +---------------------------------+ |  |
|  +--------------------------------------+  |
+--------------------------------------------+

width / height ★ 3일차

요소의 너비와 높이

div {
  width: 300px;
  height: 200px;
  width: 50%;
  height: auto;

  /* 최소/최대 크기 */
  min-width: 200px;
  max-width: 1200px;
  min-height: 100px;
  max-height: 500px;
}

padding ★ 3일차

내부 여백 (Content와 Border 사이)

div {
  /* 전체 */
  padding: 20px;

  /* 상하 좌우 */
  padding: 10px 20px;

  /* 상 좌우 하 */
  padding: 10px 20px 30px;

  /* 상 우 하 좌 (시계방향) */
  padding: 10px 20px 30px 40px;

  /* 개별 지정 */
  padding-top: 10px;
  padding-right: 20px;
  padding-bottom: 10px;
  padding-left: 20px;
}

margin ★ 3일차

외부 여백 (Border 바깥)

div {
  /* padding과 동일한 방식 */
  margin: 20px;
  margin: 10px 20px;
  margin: 10px 20px 30px 40px;

  /* 개별 지정 */
  margin-top: 10px;
  margin-right: 20px;
  margin-bottom: 10px;
  margin-left: 20px;

  /* 가로 중앙 정렬 */
  margin: 0 auto;
}

border ★ 3일차

테두리

div {
  /* width style color */
  border: 2px solid black;

  /* 개별 지정 */
  border-width: 2px;
  border-style: solid; /* solid, dashed, dotted, double, none */
  border-color: black;

  /* 방향별 */
  border-top: 1px solid red;
  border-right: 2px dashed blue;
  border-bottom: 3px dotted green;
  border-left: 4px double orange;
}

box-sizing ★ 3일차

박스 크기 계산 방식

* {
  /* width/height에 padding과 border 포함 (권장) */
  box-sizing: border-box;

  /* width/height가 content만 의미 (기본값) */
  box-sizing: content-box;
}

테두리와 그림자

border-radius ★ 6일차

모서리 둥글게

div {
  border-radius: 10px;           /* 전체 */
  border-radius: 50%;            /* 원형 */
  border-radius: 10px 20px;      /* 대각선 */
  border-radius: 10px 20px 30px 40px; /* 개별 */

  /* 개별 모서리 */
  border-top-left-radius: 10px;
  border-top-right-radius: 10px;
  border-bottom-right-radius: 10px;
  border-bottom-left-radius: 10px;
}

box-shadow

박스 그림자

div {
  /* x y blur spread color */
  box-shadow: 2px 2px 5px 0px rgba(0, 0, 0, 0.3);

  /* 내부 그림자 */
  box-shadow: inset 0 0 10px rgba(0, 0, 0, 0.5);

  /* 여러 그림자 */
  box-shadow:
    2px 2px 5px rgba(0, 0, 0, 0.3),
    -2px -2px 5px rgba(255, 255, 255, 0.5);
}

outline ★ 6일차

외곽선 (레이아웃에 영향 안줌)

input:focus {
  outline: 2px solid blue;
  outline-offset: 2px; /* 간격 */
}

/* 🔴 outline: none 으로 지우지 마십시오 — 키보드로 다니는 사람이 지금 어디인지 못 봅니다.
   마우스 클릭 때 테두리가 거슬리면 :focus-visible 로 «키보드일 때만» 보이게 합니다 (6일차) */
button:focus-visible {
  outline: 2px solid blue;
  outline-offset: 2px;
}

배경

색상 표현 방식 ★ 3일차 — HEX

.element {
  /* 색상 이름 */
  color: red;

  /* HEX */
  color: #ff0000;
  color: #f00; /* 단축형 */

  /* RGB */
  color: rgb(255, 0, 0);

  /* RGBA (투명도) */
  color: rgba(255, 0, 0, 0.5);

  /* HSL */
  color: hsl(0, 100%, 50%);

  /* HSLA */
  color: hsla(0, 100%, 50%, 0.5);
}

background-color ★ 3일차

배경 색상

  background-color: #f0f0f0;

}

background-image

배경 이미지

div {
  background-image: url('image.jpg');

}

background-repeat

배경 반복

div {
  background-repeat: repeat;    /* 반복 (기본값) */
  background-repeat: no-repeat; /* 반복 안함 */
  background-repeat: repeat-x;  /* 가로만 반복 */
  background-repeat: repeat-y;  /* 세로만 반복 */
}

background-position

배경 위치

div {
  background-position: center;
  background-position: top right;
  background-position: 50% 50%;
  background-position: 10px 20px;
}

background-size

배경 크기

div {
  background-size: auto;         /* 원본 크기 */
  background-size: cover;        /* 요소를 꽉 채움 */
  background-size: contain;      /* 요소 안에 이미지 전체 표시 */
  background-size: 100px 200px;  /* 직접 지정 */
  background-size: 50%;          /* 비율 */
}

background-attachment

배경 고정

div {
  background-attachment: scroll; /* 스크롤 (기본값) */
  background-attachment: fixed;  /* 고정 */
}

background (단축 속성)

  background: #f0f0f0 url('bg.jpg') no-repeat center/cover;

/* 웹 폰트 사용 */

레이아웃

position

요소의 위치 지정 방식

static (기본값)

relative

상대 위치

div {
  position: relative;
  top: 10px;    /* 원래 위치에서 아래로 10px */
  left: 20px;   /* 원래 위치에서 오른쪽으로 20px */
}

absolute

절대 위치 (가장 가까운 position이 있는 부모 기준)

  position: relative;
}

.child {
  position: absolute;
  top: 0;
  right: 0;
}

fixed

고정 위치 (viewport 기준)

  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
}

sticky

스크롤 시 고정

z-index

요소의 쌓임 순서 (position이 있어야 작동)

2. 선택자 우선순위 ★ 3일차

  • 인라인 스타일(style="..."): 1000점
  • ID 선택자: 100점
  • 클래스/속성/가상클래스: 10점
  • 요소/가상요소: 1점
/* 우선순위 낮음 */

/* 우선순위 중간 */

/* 우선순위 높음 */

/* 최고 우선순위 — 🔴 쓰지 마십시오. 이기려고 또 쓰게 됩니다 (3일차) */
div { color: purple !important; }
