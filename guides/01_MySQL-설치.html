MySQL 설치 가이드 (Windows)

1일차 2차시에 함께 진행합니다. 미리 해오셔도 좋습니다.

소요 시간: 설치 10분 (+ 직접 내려받으면 5~10분 더)

  • 버전 — MySQL 8.0. MySQL Installer는 8.0이 마지막 시리즈라 고를 것이 없습니다
  • 설치되는 것 — MySQL Server + Workbench(쿼리 창). 설치 프로그램 하나로 함께 깔립니다

1. 설치 파일 받기

🔴 강사가 설치 파일을 나눠줬다면 이 절은 건너뛰고 2. 설치로 가세요. 60명이 동시에 내려받으면 강의실 네트워크가 막힙니다.

직접 받아야 할 때만 아래를 따릅니다.

1-1. 다운로드 페이지 열기

https://dev.mysql.com/downloads/installer/

아래쪽 565.9M(mysql-installer-community-8.0.46.0.msi)을 받으세요.

크기 설명
위 (…-web-community-…) 2.1M 설치 중에 인터넷으로 부품을 받습니다 — 여럿이 동시에 하면 느리고 잘 끊깁니다
아래 (…-community-…) 565.9M 전부 포함된 오프라인 설치본 ✅

(x86, 32-bit) 표기는 무시하세요. 설치 프로그램만 32비트이고, 설치되는 MySQL 서버는 64비트입니다. 버전은 8.0.46 하나뿐입니다. MySQL Installer는 8.0이 마지막 시리즈라 고를 것이 없습니다.

1-2. 로그인 화면 — 가입하지 마세요

다운로드를 누르면 Oracle 로그인 화면이 뜹니다.

맨 아래 작은 파란 글씨 No thanks, just start my download. 를 누르면 바로 받아집니다.

🔴 Login · Sign Up을 누르지 마세요. 계정은 다운로드에 필요 없습니다. 가입하면 이메일 인증까지 하느라 10분씩 걸립니다.

1-3. 혹시 이 화면이 나왔다면

검색으로 들어가면 부품 목록 페이지가 나올 수 있습니다.

왼쪽 아래 MySQL Installer for Windows만 누르세요 (→ 1-1로 이어집니다).

MySQL Workbench를 따로 받지 마세요. 통합 설치본에 이미 들어 있습니다. Connector/Node.js도 안 씁니다 — 12월 Node 과목에서는 npm install mysql2로 받습니다.

2. 설치

받은 파일을 실행합니다. 화면이 순서대로 이어집니다 — 아래 순서 그대로 따라오세요.

2-1. Choosing a Setup Type — 🔴 Full을 고르세요

Full 을 고르고 Next. 오른쪽 설명에 MySQL Workbench 가 있는지 눈으로 확인하세요.

선택지
Server only ❌ 처음엔 이게 선택돼 있습니다. 그냥 Next를 누르면 Workbench가 안 깔려 쿼리 창을 못 엽니다
Client only ❌ 서버가 없습니다
Full ✅ Server + Workbench가 함께
Custom △ 직접 고르는 방식. 트리에서 →로 옮겨야 해서 실수하기 쉽습니다

Full은 Router·Shell·문서까지 함께 깔려 용량이 큽니다. 그래도 Workbench 누락보다 낫습니다.

2-2. Check Requirements

빨간 항목이 있으면 Execute, 없으면 그냥 Next.

오프라인 설치본에는 Download 단계가 아예 나오지 않습니다. 바로 Installation으로 넘어갑니다.

2-3. Installation — Execute

Execute를 누르면 설치가 시작됩니다. 몇 분 걸립니다.

목록에 MySQL Workbench 가 있는지 다시 한 번 확인하세요. 없으면 < Back으로 돌아가 Full을 고르십시오.

다 끝나면 Execute가 Next로 바뀝니다. 그때 누르세요.

2-4. Product Configuration — Next

여기부터는 설정입니다. 지금까지가 파일 복사였다면, 이제 포트·비밀번호를 정합니다.

세 제품이 차례로 나오는데 우리가 신경 쓸 것은 MySQL Server 하나입니다. MySQL Router와 Samples and Examples는 쓰지 않으므로 나오는 대로 Next/Finish로 넘기십시오.

2-5. Type and Networking — 기본값

전부 그대로 두고 Next.

  • Config Type — Development Computer (메모리를 적게 씁니다)
  • Port — 3306 ← 교안이 쓰는 포트입니다
  • Show Advanced and Logging Options — 체크하지 마세요 (설정 화면이 늘어납니다)

2-6. Authentication Method — 기본값

위쪽 Use Strong Password Encryption (RECOMMENDED) 그대로 Next.

노란 경고는 "옛 커넥터는 이 방식을 지원 못 할 수 있다"는 안내입니다. 12월 Node 과목에서 쓸 mysql2는 이 방식을 지원하므로 그대로 두면 됩니다.

2-7. Accounts and Roles — 🔴 비밀번호

root 계정의 비밀번호를 정합니다.

  • 수업에서는 기억하기 쉬운 것으로 — 예: root
  • Password strength: Weak 라고 빨갛게 떠도 괜찮습니다. 경고일 뿐 막지 않습니다
  • 🔴 반드시 메모하세요. 완전히 잊으면 재설치가 빠릅니다 (아래 참고)
  • Add User는 하지 않습니다. root 하나로 진행합니다

실무에서는 절대 이렇게 하지 않습니다. 교육용 로컬 DB라서 이렇게 하는 것입니다.

비밀번호를 나중에 바꾸려면 — 재설치할 필요 없습니다. 지금 것을 기억하고 있다면 셋 중 하나로 바꿉니다.

ALTER USER 'root'@'localhost' IDENTIFIED BY '새비밀번호';
  • Workbench에서 Server → Users and Privileges → root 선택 → 비밀번호 변경 → Apply
  • 시작 메뉴 → MySQL Installer → MySQL Server 옆 Reconfigure → 이 화면까지 다시 진행

2-8. Windows Service — 기본값

전부 그대로 두고 Next.

  • Windows Service Name — MySQL80 ← 문제 해결에서 이 이름을 씁니다
  • Start the MySQL Server at System Startup — ✅ 체크된 채로 두세요
  • Standard System Account — 그대로

자동 시작을 꺼두면 컴퓨터를 켤 때마다 직접 서비스를 시작해야 하고, 잊으면 Workbench가 접속되지 않습니다. 수업 중에는 켜 두는 편이 안전합니다.

나중에 자동 실행을 끄고 싶다면 (수업이 끝난 뒤 등)

MySQL은 서비스로 등록돼 부팅할 때마다 백그라운드에서 돕니다. 평소에 안 쓰면 꺼둘 수 있습니다.

  1. Win + R → services.msc → 확인
  2. 목록에서 MySQL80 찾기
  3. 마우스 오른쪽 → 속성
  4. 시작 유형 을 자동 → 수동 으로 변경 → 확인

이제 부팅해도 자동으로 켜지지 않습니다.

다시 쓸 때는 직접 시작해야 합니다 — 같은 화면에서 MySQL80 오른쪽 클릭 → 시작.

🔴 끄기 전에 알아둘 것 — 서비스가 멈춰 있으면 Workbench에서 Can't connect to MySQL server 오류가 납니다. 고장이 아니라 꺼져 있는 것입니다. 수업 기간에는 그냥 켜 두시길 권합니다.

2-9. Server File Permissions — 기본값

첫 번째 항목이 이미 선택돼 있습니다. 그대로 Next.

데이터 폴더의 접근 권한을 MySQL 서비스 계정과 관리자에게만 주겠다는 뜻입니다. 아래 두 선택지는 권한을 직접 관리하겠다는 것이라 교육용으로는 필요 없습니다.

2-10. Apply Configuration — Execute

Execute를 누르면 여덟 단계가 위에서부터 차례로 초록 체크로 바뀝니다.

Initializing database (may take a long time) 에서 가장 오래 멈춥니다. 정상입니다 — 기다리세요.

이렇게 되면 성공입니다.

여덟 단계가 전부 초록 체크이고 아래에 was successful 이라고 나오면 Finish.

빨간 ✗ 가 뜨면 Log 탭에서 원인을 볼 수 있습니다. 흔한 원인은 포트 3306 충돌(이전에 설치한 MySQL·MariaDB)입니다 — 아래 「문제 해결」 참조.

2-11. MySQL Router Configuration — 그냥 Finish

아무것도 건드리지 말고 Finish.

  • 맨 위 Bootstrap MySQL Router… 체크를 하지 마세요. 해제된 것이 정상입니다
  • 그래서 아래 입력란이 전부 회색입니다 — 채울 것이 없습니다

입력란이 많아 뭔가 적어야 할 것처럼 보이지만 아닙니다. Router는 서버 여러 대에 트래픽을 나눠주는 도구입니다. Full로 설치해서 딸려왔을 뿐, 우리는 Workbench로 내 컴퓨터의 서버에 직접 붙습니다.

2-12. Connect To Server — 비밀번호 확인

  1. Password: 칸에 아까 정한 비밀번호(root) 입력
  2. Check 클릭 → 초록 체크가 뜹니다
  3. 그러면 Next >가 활성화됩니다

🔴 Next가 회색이라고 막힌 게 아닙니다. Check를 눌러 비밀번호가 맞는지 확인해야 열립니다.

이렇게 되면 맞습니다.

  • Status가 초록색 Connection succeeded.
  • Check 옆에 초록 체크 ✅
  • Next >가 활성화 → 누릅니다

🔴 비밀번호가 틀리면 여기서 빨간 오류가 납니다. 이 화면은 비밀번호를 처음으로 실제 검증하는 자리이기도 합니다 — 여기서 통과하면 Workbench 접속도 같은 비밀번호로 됩니다.

2-13. Apply Configuration — Execute

Execute를 누르면 두 단계가 지나갑니다.

was successful 이 나오면 Finish.

2-14. Installation Complete — 끝

위 그림처럼 Start MySQL Shell after setup 체크를 해제하고 Finish.

체크박스
✅ Start MySQL Workbench after setup 켜 둡니다 — 바로 접속을 확인합니다
⬜ Start MySQL Shell after setup 끕니다 — 우리는 Shell을 쓰지 않습니다

Shell을 켜두면 검은 명령줄 창이 같이 떠서 처음 보는 사람은 당황합니다. 우리는 Workbench 하나로 진행합니다.

설치가 전부 끝났습니다. Workbench가 자동으로 열립니다 → 바로 §3으로.

3. 확인

설치가 끝나면 MySQL Workbench가 자동으로 열립니다. (안 열렸으면 시작 메뉴에서 MySQL Workbench 실행)

1) 왼쪽 아래 MySQL Connections의 Local instance MySQL80 타일 → 클릭 (아래에 root · localhost:3306 이라고 적혀 있습니다)

2) 비밀번호를 묻는 창이 뜹니다.

  • Password: — 설치 때 정한 root
  • Save password in vault 체크 → 다음부터 안 묻습니다
  • OK

3) 이 화면이 나오면 접속 성공입니다.

  • 위쪽에 Local instance MySQL80 탭
  • 가운데 Query 1 — 여기에 SQL을 씁니다
  • 왼쪽 아래 Schemas 탭을 누르면 데이터베이스 목록이 나옵니다 (처음엔 Administration 탭이 열려 있습니다)

여기까지 되면 설치는 끝입니다. 나머지(§4~§6)는 수업에서 함께 합니다.

🔴 타일이 안 보이거나 접속이 안 되면 서버가 안 켜진 것입니다. 아래 「문제 해결」을 보세요.

4. 실습 데이터베이스 만들기

Query 1 창에 아래 두 줄을 입력하고, 한 줄씩 Ctrl + Enter로 실행합니다.

CREATE DATABASE newsdb CHARACTER SET utf8mb4;
USE newsdb;
  • CHARACTER SET utf8mb4 — 한글이 깨지지 않게 합니다
  • USE — "앞으로 이 데이터베이스에서 작업한다"

이렇게 되면 성공입니다.

확인할 곳이 두 군데입니다.

어디 무엇이 보여야 하나
아래 Output 두 줄 모두 초록 체크 ✅ (1 row(s) affected · 0 row(s) affected)
왼쪽 SCHEMAS newsdb 가 목록에 있음

0 row(s) affected는 오류가 아닙니다. USE는 "이제 여기서 작업한다"고 선언만 하므로 바뀐 행이 없는 것이 정상입니다.

🔴 왼쪽에 newsdb가 안 보이면 왼쪽 아래 Schemas 탭을 누르고 SCHEMAS 옆 새로고침(회전 화살표) 을 클릭하세요. 만들어졌는데 화면만 안 바뀐 것입니다.

sakila · sys · world는 설치 때 함께 들어온 예제입니다. 우리는 쓰지 않습니다.

5. 쿼리 실행하는 법

Query 1 창에 입력하고 실행해 봅니다.

SELECT 1;

Result Grid에 1 이 나오면 준비 완료입니다.

실행하는 두 가지 방법

방법 무엇이 실행되나
Ctrl + Enter 커서가 놓인 문장 하나 — 수업에서 주로 씁니다
번개(⚡) 아이콘 편집창 전체 — 파일을 통째로 실행할 때

🔴 여러 문장을 써 놓고 Ctrl + Enter를 누르면 커서가 있는 문장만 실행됩니다. "왜 하나만 되지?" 싶을 때가 이 경우입니다.

6. 실습 데이터 넣기

1) 상단 메뉴 File → Open SQL Script... → 배포된 articles.sql 선택

2) 새 탭에 파일 내용이 열립니다.

3) 번개(⚡) 아이콘을 눌러 전체 실행합니다.

🔴 여기서는 Ctrl + Enter가 아니라 번개(⚡)입니다. 문장이 수백 개라 하나씩 실행할 수 없습니다.

⚠️ 노란 경고 1051 Unknown table 'newsdb.articles' 는 정상입니다. 파일 맨 앞의 DROP TABLE IF EXISTS articles 가 "있으면 지워라"인데, 처음 실행할 때는 지울 것이 없어서 뜨는 알림입니다. 그냥 넘어가면 됩니다.

4) 잘 들어갔는지 확인합니다.

SELECT COUNT(*) FROM articles;

500 이 나오면 성공입니다.

확인할 곳이 두 군데입니다.

어디 무엇이 보여야 하나
Result Grid 500
아래 Output INSERT INTO articles … 줄이 500 row(s) affected · Warnings: 0

Warnings: 0 이 중요합니다. 여기에 경고가 있으면 한글이 깨져 들어갔을 수 있습니다. 그때는 아래 「문제 해결」의 한글 항목을 보세요.

왼쪽 SCHEMAS → newsdb → Tables 를 펼치면 articles 가 보입니다.

4일차부터는 reporters.sql도 같은 방법으로 실행합니다 — 🔴 articles.sql 다음에 실행하세요.

문제 해결

증상 원인 · 해결
설치 중 오류가 뜬다 백신을 잠시 중지하고 재시도
시작 메뉴에 Workbench가 아예 없다 첫 화면에서 Server only로 깔렸습니다. 설치 파일을 다시 실행 → Full 선택 → Next. 서버는 그대로 두고 Workbench만 추가됩니다 (재설치 아님)
Workbench가 안 열린다 시작 메뉴에서 다시 실행. 그래도 안 되면 재부팅
비밀번호가 틀리다고 한다 설치 때 정한 것과 대소문자까지 확인. 모르면 재설치가 빠릅니다
포트 3306이 사용 중 이전에 설치한 MySQL·MariaDB가 있습니다. 제어판에서 제거 후 재설치
한글이 ???로 들어간다 접속 charset 문제. 쿼리 창에서 SET NAMES utf8mb4; 먼저 실행하고 articles.sql을 다시 넣으세요 (DROP TABLE 부터 다시)
Local instance MySQL80 타일이 없다 서비스 미실행. 작업 관리자 → 서비스 → MySQL80 → 시작
Can't connect to MySQL server 서비스가 꺼져 있습니다. Win + R → services.msc → MySQL80 오른쪽 클릭 → 시작. 자동 실행을 껐다면 매번 이렇게 켜야 합니다 (§2-8 참조)
articles.sql 실행이 느리다 정상입니다. 500건 삽입에 몇 초 걸립니다

혼자 오래 붙들지 마세요. 5분 넘게 막히면 손 드시면 됩니다. 설치가 끝내 안 되면 옆 사람 화면으로 함께 진행하고, 쉬는 시간에 해결합니다.

참고 — 우리가 쓰지 않는 것

설치를 검색하면 나오는 것들인데, 이 과정에서는 쓰지 않습니다.

  • Docker — 가상화 설정이 필요해 교육장 PC에서 문제가 생기기 쉽습니다
  • WSL / 리눅스 — 이 과정은 Windows에서 그대로 진행합니다
  • 명령줄(mysql) — Workbench로 충분합니다. 관심 있으면 나중에

설치 프로그램 하나면 끝납니다.
