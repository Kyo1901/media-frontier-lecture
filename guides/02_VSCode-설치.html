VS Code 설치 가이드 (Windows)

HTML/CSS 1일차(11/02) 전에 미리 해두세요. 수업 중에 설치하면 1차시가 통째로 날아갑니다.

파일 이름의 02_ 는 가이드 순서입니다. 작업 폴더의 03-html-css 와는 상관없습니다.

소요 시간: 설치 5분 (+ 내려받기 2~3분)

  • 무엇인가 — 코드를 쓰는 프로그램(편집기)입니다. 메모장의 개발자용이라고 보면 됩니다
  • 왜 필요한가 — 오타를 색으로 잡아주고, 닫는 태그를 자동으로 넣어주고, 파일 이름이 .txt 로 잘못 저장되는 사고를 막아줍니다
  • 🔴 12월 React·Node 수업까지 계속 씁니다. 지금 한 번 깔면 끝입니다

1. 설치 파일 받기

🔴 강사가 설치 파일을 나눠줬다면 이 절은 건너뛰고 2. 설치로 가세요.

https://code.visualstudio.com/

파란 Download for Windows 버튼을 누릅니다. VSCodeUserSetup-x64-<버전>.exe 파일이 받아집니다. (약 100MB)

계정 가입도, 로그인도 필요 없습니다. 무료입니다.

2. 설치

받은 파일을 더블클릭합니다. 고를 것이 거의 없지만 두 화면만 봐야 합니다.

① 사용권 계약 — 「동의합니다」를 고르기 전에는 「다음」이 눌리지 않습니다.

② 추가 작업 선택 — 아래 두 개를 체크하세요.

항목 어떻게
Code(으)로 열기 작업을 Windows 탐색기 파일 상황에 맞는 메뉴에 추가 ✅ 체크
Code(으)로 열기 작업을 Windows 탐색기 디렉터리 상황에 맞는 메뉴에 추가 ✅ 체크
지원되는 파일 형식에 대한 편집기로 Code 등록 ✅ 체크 (기본값)
PATH에 추가 ✅ 체크 (기본값)
바탕 화면에 바로 가기 만들기 취향껏

🔴 위의 두 개를 꼭 체크하세요. 폴더에 오른쪽 클릭해서 바로 열 수 있게 됩니다. 안 했어도 괜찮습니다 — VS Code 안에서 파일 → 폴더 열기 로 하면 됩니다.

설치가 끝나면 「VS Code 실행」 에 체크하고 마침을 누릅니다.

3. 한국어로 바꾸기 (선택)

처음 실행하면 영어입니다. Windows 표시 언어가 한국어면 오른쪽 아래에 한국어 팩 안내가 뜨기도 합니다 — 뜨면 설치·다시 시작 버튼을 누르면 됩니다.

안 뜨는 경우가 더 많습니다. 그때는 직접 깝니다:

  1. 왼쪽 세로 막대에서 네모 네 개 아이콘(확장) 클릭 — 또는 Ctrl+Shift+X
  2. 검색창에 Korean 입력
  3. Korean Language Pack for Visual Studio Code 의 Install 클릭
  4. 오른쪽 아래 Restart 클릭

영어 그대로 쓰셔도 전혀 문제없습니다. 수업에서는 양쪽 이름을 다 말합니다.

4. 작업 폴더 열기

이것까지 해두면 1일차 준비 끝입니다.

  1. 파일 → 폴더 열기 (File → Open Folder)
  2. C:\dev\workspace\03-html-css 를 선택
    • 폴더가 없으면 그 자리에서 새 폴더로 만드세요
    • C:\dev\workspace 를 아직 안 만들었다면 00_워크스페이스.md 를 먼저 보세요
  3. 「이 폴더에 있는 파일 작성자를 신뢰합니까?」가 뜨면 예, 작성자를 신뢰합니다
  4. 왼쪽 탐색기에서 새 폴더 아이콘 → day01

🔴 03-html-css 입니다. 02 가 아닙니다 — 워크스페이스 가이드의 번호를 그대로 씁니다. 🔴 수업 첫날 파일을 여기에 만듭니다. day01 까지 미리 만들어 두세요.
