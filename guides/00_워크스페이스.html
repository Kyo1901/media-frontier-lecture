작업 폴더 만들기 — 74일을 담을 곳

1일차 시작할 때 함께 만듭니다. 5분이면 됩니다.

이 과정은 10과목 74일입니다. SQL·HTML·자바스크립트·React·프로젝트까지 파일이 계속 쌓입니다. 처음에 자리를 정해두지 않으면 나중에 찾지 못합니다.

📌 이 폴더가 나중에 그대로 Git 저장소가 되고, 수료 후에는 "74일 학습 기록" 이라는 포트폴리오가 됩니다.

1. 어디에 만드나 — 🔴 여기가 제일 중요합니다

C:\dev\workspace 에 만듭니다.

  1. Win + E (파일 탐색기) → 왼쪽에서 로컬 디스크 (C:) 클릭
  2. 빈 곳에 오른쪽 클릭 → 새로 만들기 → 폴더 → dev
  3. dev 안으로 들어가 다시 폴더 만들기 → workspace

완성: C:\dev\workspace

왜 하필 여기인가

피해야 할 것 이유
🔴 바탕 화면 · 내 문서 한국 Windows는 이 폴더들이 OneDrive에 자동 동기화되는 경우가 많습니다. 12월 React·Node 수업에서 파일 수만 개짜리 폴더가 생기는데, OneDrive가 그걸 계속 올리려 하면서 컴퓨터가 멈춥니다
🔴 경로에 한글·공백 C:\Users\홍길동\바탕 화면\수업\ 같은 경로는 npm·Node가 오류를 냅니다. 12월에 반드시 걸립니다
🔴 USB · 외장하드 빼놓고 오면 그날 수업을 못 합니다

C:\dev\workspace는 짧고, 영문이고, 동기화되지 않습니다.

회사·학원 PC라 C:\ 에 폴더를 못 만들면 D:\dev\workspace 도 괜찮습니다. 한글과 공백만 없으면 됩니다.

2. 과목 폴더 만들기

C:\dev\workspace 안에 과목별 폴더를 만듭니다. 수업 진도에 맞춰 그때그때 하나씩 만들면 됩니다.

번호를 꼭 붙이세요. 그래야 폴더가 수업 순서대로 정렬됩니다. 이름은 영문 소문자에 -(하이픈)만 씁니다.

3. 과목 폴더 안은 이렇게

오늘 만들 01-db 를 예로 들면:

규칙은 두 가지뿐입니다

① 받은 파일은 data\ 에, 내가 쓴 것은 dayNN\ 에

articles.sql 같은 배포 파일을 내 답안과 같은 폴더에 두면, 나중에 파일을 다시 받아 덮어쓸 때 내 답안까지 날아갑니다.

② 파일 이름은 받은 그대로

practice-1.sql 을 연습1.sql 로 바꾸지 마세요. 강사가 "practice-2 열어보세요" 라고 할 때 못 찾습니다.

4. 오늘 할 일

  1. C:\dev\workspace\01-db\data 폴더까지 만들기
  2. 나눠준 articles.sql 을 data\ 에 넣기
  3. C:\dev\workspace\01-db\day01 폴더 만들기
  4. 나눠준 practice-1.sql·practice-2.sql 을 day01\ 에 넣기

이제 MySQL 설치로 넘어갑니다.

Workbench에서 File → Open SQL Script... 를 누르면 C:\dev\workspace\01-db\data 로 찾아가면 됩니다.

5. 앞으로 — Git

지금은 폴더만 씁니다. 저장 버튼이 곧 백업입니다.

Git 기초는 따로 배웁니다 — 날짜는 따로 알려 드립니다 (이 과목 담당이 아닙니다). 그날 지금까지 쌓인 DB 9일치 파일을 그대로 버전 관리에 넣을 수 있습니다.

그래서 지금 폴더를 잘 만들어두면 다시 정리할 일이 없습니다. 폴더 하나가 그대로 저장소가 됩니다.

그때까지 백업은?

  • 하루 끝나면 C:\dev\workspace 폴더를 통째로 압축해서 메일이나 클라우드에 하나 올려두세요
  • PC가 갑자기 고장 나도 그날치는 남습니다
  • Git을 배운 뒤에는 Git이 이 역할을 대신합니다
