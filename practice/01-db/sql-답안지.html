문제 1. SELECT 기본

문제
departments 테이블의 모든 컬럼, 모든 행을 조회하시오.

정답

SELECT * FROM departments;

해설

*는 모든 컬럼을 의미합니다. 실무에서는 필요한 컬럼만 명시하는 것이 좋지만, 테이블 구조를 처음 확인할 때는 SELECT *가 편리합니다.

문제 12. LIKE (시작 문자열)

문제

(컬럼: name, email)

해설

LIKE의 %는 0개 이상의 임의 문자, _는 정확히 1개의 문자를 의미합니다. 's%'는 's'로 시작하는 모든 문자열입니다. NULL 값은 비교 결과가 NULL이므로 자동으로 제외됩니다.

문제 24. 날짜 비교

문제
2022년 1월 1일 이후에 입사한 직원의 이름과 입사일을 조회하시오.
(컬럼: emp_name, hire_date)

정답

문제 107. 관계 나눗셈 (NOT EXISTS)

문제
모든 상품 카테고리(전자기기, 액세서리, 도서, 가구)의 상품을 각각 한 번 이상 구매한 고객의 이름을 구하시오(취소 주문 제외).
(컬럼: name)

정답

SELECT c.name
FROM customers c
WHERE NOT EXISTS (
  SELECT 1 FROM (SELECT DISTINCT category FROM products) cat
  WHERE NOT EXISTS (
    SELECT 1
    FROM orders o
    JOIN order_items oi ON o.order_id = oi.order_id
    JOIN products p     ON oi.product_id = p.product_id
    WHERE o.customer_id = c.customer_id
      AND o.status <> 'CANCELLED'
      AND p.category = cat.category
  )
);

해설

'모든 ~를 만족하는' 조건은 이중 NOT EXISTS로 표현합니다: '고객이 구매하지 않은 카테고리가 하나도 없다'. 또는 GROUP BY c.customer_id HAVING COUNT(DISTINCT p.category) = (SELECT COUNT(DISTINCT category) FROM products)로도 풀 수 있습니다.

문제 108. 중앙값

문제
전체 직원 급여의 중앙값을 구하시오(짝수 개이면 가운데 두 값의 평균). 별칭은 median_salary입니다.
(컬럼: median_salary)

정답

WITH t AS (
  SELECT salary,
         ROW_NUMBER() OVER (ORDER BY salary) AS rn,
         COUNT(*) OVER () AS cnt
  FROM employees
)
SELECT AVG(salary) AS median_salary
FROM t
WHERE rn IN ((cnt + 1) / 2, (cnt + 2) / 2);

해설

순번(rn)과 전체 건수(cnt)를 구한 뒤, 홀수 개이면 가운데 1행, 짝수 개이면 가운데 2행을 골라 평균을 냅니다. (cnt+1)/2와 (cnt+2)/2가 정수 나눗셈으로 홀수일 땐 같은 값, 짝수일 땐 연속한 두 값이 됩니다. 대부분의 DB가 MEDIAN 함수를 기본 제공하지 않아 자주 출제되는 문제입니다.

문제 109. 카테고리별 매출 상위 2개 상품

문제
취소 주문을 제외하고, 카테고리별로 매출액이 높은 상위 2개 상품을 구하시오. 동점은 없다고 가정하고 ROW_NUMBER를 사용합니다. category, 순위 순으로 정렬하며 별칭은 revenue, rn입니다.
(컬럼: category, product_name, revenue, rn)

정답

WITH sales AS (
  SELECT p.category, p.product_name,
         SUM(oi.quantity * oi.unit_price) AS revenue
  FROM order_items oi
  JOIN orders o   ON oi.order_id = o.order_id
  JOIN products p ON oi.product_id = p.product_id
  WHERE o.status <> 'CANCELLED'
  GROUP BY p.product_id, p.category, p.product_name
), ranked AS (
  SELECT category, product_name, revenue,
         ROW_NUMBER() OVER (PARTITION BY category ORDER BY revenue DESC) AS rn
  FROM sales
)
SELECT category, product_name, revenue, rn
FROM ranked
WHERE rn <= 2
ORDER BY category, rn;

해설

CTE를 여러 개 이어(WITH a AS (...), b AS (...)) 단계별로 가공하는 방식입니다. ① 상품별 매출 집계 ② 카테고리 내 순위 부여 ③ 상위 N 필터. 복잡한 쿼리를 단계로 나누면 읽기 쉽고 디버깅하기 쉽습니다.

문제 110. 누적 구매액이 처음 50만 원을 넘은 주문

문제
취소 주문을 제외하고, 고객별로 주문일 순으로 구매 금액을 누적했을 때 누적액이 처음으로 500,000원 이상이 되는 주문의 고객번호, 주문번호, 주문일, 누적액을 customer_id 순으로 구하시오. 같은 날 주문은 없습니다. 누적액이 500,000원에 도달하지 못한 고객은 제외합니다. 별칭은 running_total입니다.
(컬럼: customer_id, order_id, order_date, running_total)

정답

WITH order_total AS (
  SELECT o.customer_id, o.order_id, o.order_date,
         SUM(oi.quantity * oi.unit_price) AS total
  FROM orders o
  JOIN order_items oi ON o.order_id = oi.order_id
  WHERE o.status <> 'CANCELLED'
  GROUP BY o.order_id, o.customer_id, o.order_date
), running AS (
  SELECT customer_id, order_id, order_date,
         SUM(total) OVER (
           PARTITION BY customer_id ORDER BY order_date
         ) AS running_total
  FROM order_total
), hit AS (
  SELECT *,
         ROW_NUMBER() OVER (
           PARTITION BY customer_id ORDER BY order_date
         ) AS rn
  FROM running
  WHERE running_total >= 500000
)
SELECT customer_id, order_id, order_date, running_total
FROM hit
WHERE rn = 1
ORDER BY customer_id;

해설

종합 문제입니다. ① 주문 단위 금액 집계 → ② 고객별 누적합(윈도 함수) → ③ 임계값을 넘긴 행 중 첫 번째만 선택(ROW_NUMBER). 마일리지 등급 승급 시점, 첫 목표 달성일 같은 분석에서 흔히 쓰이는 패턴입니다.
