## 목차

- **초급** (1~40번, 40문제): SELECT 기본, 조건·정렬, 집계 함수, GROUP BY, 기본 DML
- **중급** (41~90번, 50문제): JOIN, 서브쿼리, CASE·함수, 집합 연산, DDL·고급 DML, 분석 쿼리
- **고급** (91~110번, 20문제): 윈도 함수, CTE, 재귀 CTE, 종합 분석 쿼리

## 0. 실습용 샘플 데이터베이스

모든 문제는 아래 6개 테이블로 구성된 하나의 샘플 DB를 사용합니다. **SQLite 문법** 기준이며, 풀이 페이지에서 바로 실행·채점할 수 있습니다.

```text
departments 1 ──< employees >── 1 employees (manager_id: 자기 참조, 상사)
customers   1 ──< orders    1 ──< order_items >── 1 products
```

| 테이블 | 설명 | 컬럼 |
|---|---|---|
| `departments` | 부서 | dept_id, dept_name, location |
| `employees` | 직원 | emp_id, emp_name, dept_id, job_title, salary, hire_date, manager_id |
| `customers` | 고객 | customer_id, name, city, grade, joined_date, email |
| `products` | 상품 | product_id, product_name, category, price, stock |
| `orders` | 주문 | order_id, customer_id, order_date, status |
| `order_items` | 주문상세 | item_id, order_id, product_id, quantity, unit_price |

**참고 사항**
- 날짜는 `YYYY-MM-DD` 형식의 TEXT, 금액은 원 단위 정수입니다.
- `orders.status` 값: `PAID`(결제), `SHIPPED`(배송 중), `DELIVERED`(배송 완료), `CANCELLED`(취소)
- `customers.grade` 값: `BRONZE` < `SILVER` < `GOLD` < `VIP`
- `employees.manager_id`는 직속 상사의 `emp_id`이며, 최상위자(대표)는 NULL입니다.
- 직원 중 `dept_id`가 NULL인 사람, 직원이 없는 부서, 주문 이력이 없는 고객·상품이 일부러 포함되어 있습니다(OUTER JOIN, NULL 처리 연습용).
- 'DML/DDL 문제'(INSERT/UPDATE/DELETE/CREATE 등)는 문제마다 **초기 상태의 DB**에서 시작하며, 실행 후의 결과 상태로 채점합니다.
