SQL 연습 문제지

총 110문제 — 초급 40 · 중급 50 · 고급 20
난이도와 개념이 점진적으로 올라가도록 번호 순서대로 구성되어 있습니다. 정답과 해설은 sql-답안지.md에 있습니다.

목차

  • 초급 (1~40번, 40문제): SELECT 기본, 조건·정렬, 집계 함수, GROUP BY, 기본 DML
  • 중급 (41~90번, 50문제): JOIN, 서브쿼리, CASE·함수, 집합 연산, DDL·고급 DML, 분석 쿼리
  • 고급 (91~110번, 20문제): 윈도 함수, CTE, 재귀 CTE, 종합 분석 쿼리

0. 실습용 샘플 데이터베이스

모든 문제는 아래 6개 테이블로 구성된 하나의 샘플 DB를 사용합니다. MySQL 8.0 문법 기준입니다. 풀이 페이지(SQL 연습장)에서 바로 실행·채점할 수 있고, Workbench 에서 같은 DB 를 만들어(맨 아래 SQL) 풀어도 같은 답이 나옵니다.

departments 1 ──< employees >── 1 employees (manager_id: 자기 참조, 상사)
customers   1 ──< orders    1 ──< order_items >── 1 products
테이블 설명 컬럼
departments 부서 dept_id, dept_name, location
employees 직원 emp_id, emp_name, dept_id, job_title, salary, hire_date, manager_id
customers 고객 customer_id, name, city, grade, joined_date, email
products 상품 product_id, product_name, category, price, stock
orders 주문 order_id, customer_id, order_date, status
order_items 주문상세 item_id, order_id, product_id, quantity, unit_price

참고 사항

  • 날짜는 DATE(YYYY-MM-DD), 금액은 원 단위 정수(INT)입니다.
  • orders.status 값: PAID(결제), SHIPPED(배송 중), DELIVERED(배송 완료), CANCELLED(취소)
  • customers.grade 값: BRONZE < SILVER < GOLD < VIP
  • employees.manager_id는 직속 상사의 emp_id이며, 최상위자(대표)는 NULL입니다.
  • 직원 중 dept_id가 NULL인 사람, 직원이 없는 부서, 주문 이력이 없는 고객·상품이 일부러 포함되어 있습니다(OUTER JOIN, NULL 처리 연습용).
  • 'DML/DDL 문제'(INSERT/UPDATE/DELETE/CREATE 등)는 문제마다 초기 상태의 DB에서 시작하며, 실행 후의 결과 상태로 채점합니다.

Workbench 에서 직접 만들어 풀려면

아래 SQL 을 통째로 실행하면 같은 DB(practice)가 생깁니다. 🔴 수업용 newsdb 와는 다른 DB 입니다 — DML/DDL 문제를 풀다 망가지면 이 SQL 을 다시 실행하세요.

DROP DATABASE IF EXISTS practice;
CREATE DATABASE practice;
USE practice;

CREATE TABLE departments (
  dept_id   INT PRIMARY KEY,
  dept_name VARCHAR(20) NOT NULL,
  location  VARCHAR(10) NOT NULL
);
CREATE TABLE employees (
  emp_id     INT PRIMARY KEY,
  emp_name   VARCHAR(20) NOT NULL,
  dept_id    INT,
  job_title  VARCHAR(20) NOT NULL,
  salary     INT NOT NULL,
  hire_date  DATE NOT NULL,
  manager_id INT,
  FOREIGN KEY (dept_id) REFERENCES departments(dept_id),
  FOREIGN KEY (manager_id) REFERENCES employees(emp_id)
);
CREATE TABLE customers (
  customer_id INT PRIMARY KEY,
  name        VARCHAR(20) NOT NULL,
  city        VARCHAR(10) NOT NULL,
  grade       VARCHAR(10) NOT NULL,
  joined_date DATE NOT NULL,
  email       VARCHAR(50)
);
CREATE TABLE products (
  product_id   INT PRIMARY KEY,
  product_name VARCHAR(50) NOT NULL,
  category     VARCHAR(20) NOT NULL,
  price        INT NOT NULL,
  stock        INT NOT NULL
);
CREATE TABLE orders (
  order_id    INT PRIMARY KEY,
  customer_id INT NOT NULL,
  order_date  DATE NOT NULL,
  status      VARCHAR(10) NOT NULL,
  FOREIGN KEY (customer_id) REFERENCES customers(customer_id)
);
CREATE TABLE order_items (
  item_id    INT PRIMARY KEY,
  order_id   INT NOT NULL,
  product_id INT NOT NULL,
  quantity   INT NOT NULL,
  unit_price INT NOT NULL,
  FOREIGN KEY (order_id) REFERENCES orders(order_id),
  FOREIGN KEY (product_id) REFERENCES products(product_id)
);
